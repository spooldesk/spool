SPOOLDESK - START HERE / НАЧНИТЕ ЗДЕСЬ

1. Start Docker / Запустите Docker.
2. Extract the entire ZIP / Полностью распакуйте ZIP.
3. Open the launcher for your OS / Откройте файл своей ОС:

   Windows: INSTALL-WINDOWS.cmd
   macOS:   INSTALL-MACOS.command
   Linux:   INSTALL-LINUX.sh (Run in Terminal / Запустить в терминале)

Setup confirmation / Подтверждение:
   1 or Enter = install / 1 или Enter = установить
   0 = cancel / 0 = отменить

Guides / Инструкции:
   INSTALLATION.md     - English installation guide
   INSTALLATION_RU.md  - Установка на русском
   TROUBLESHOOTING.md  - Errors and recovery / Ошибки и восстановление

Keep this folder after setup. Open the same launcher for later starts.
Сохраните эту папку. Для следующих запусков открывайте тот же файл.

Do not edit installer/ or package/. Do not delete Docker volumes to fix errors.
Не редактируйте installer/ и package/. Не удаляйте тома Docker при ошибках.

The wizard is for a new installation or restarting its own installation.
Мастер создаёт новую установку или запускает свою существующую установку.
