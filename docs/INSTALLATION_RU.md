# Установка Spooldesk

Одна организация на одной self-hosted установке. Нужны работающий Docker,
доступ в интернет для первой загрузки PostgreSQL и постоянная папка на диске.
Python, Git и отдельная установка лендинга не нужны.

## 1. Подготовить Docker

| ОС | Требования |
| --- | --- |
| Windows | [Docker Desktop](https://docs.docker.com/desktop/setup/install/windows-install/), режим Linux containers |
| macOS Intel / Apple Silicon | [Docker Desktop](https://docs.docker.com/desktop/setup/install/mac-install/) для своего процессора |
| Linux x86-64 / ARM64 | [Docker Engine](https://docs.docker.com/engine/install/) и [Compose v2+](https://docs.docker.com/compose/install/linux/) |

Запусти Docker Desktop и дождись готовности движка. На Linux служба Docker
должна работать, а пользователь — иметь доступ к ней. Мастер ничего не
устанавливает в систему и не меняет разрешения. Удалённые Docker contexts
не поддерживаются. Используй обычного пользователя с доступом к Docker.

## 2. Скачать и распаковать

**[Скачать установочный ZIP v0.1.0-rc.9](https://github.com/spooldesk/spool/releases/download/v0.1.0-rc.9/spooldesk-v0.1.0-rc.9-installer.zip)**

[Контрольная сумма ZIP](https://github.com/spooldesk/spool/releases/download/v0.1.0-rc.9/spooldesk-v0.1.0-rc.9-installer.zip.sha256)
позволяет проверить загрузку. Внутренние файлы мастер проверяет автоматически.
Контрольные суммы проверяют целостность, но не заменяют цифровую подпись:
скачивай архив из официального GitHub Release. Если репозиторий закрыт,
требуется вход в GitHub с доступом к нему.

Выбирай **installer.zip**, а не автоматически созданный GitHub «Source code».
Распакуй весь архив в новую постоянную папку, например `Документы/Spooldesk`.
Не запускай установщик внутри ZIP. Избегай системных каталогов, общих папок
и запятых в пути. Пробелы и кириллица поддерживаются.
Не перемещай и не удаляй папку после установки.

## 3. Открыть установщик

| ОС | Файл |
| --- | --- |
| Windows | **INSTALL-WINDOWS.cmd** — двойной щелчок |
| macOS | **INSTALL-MACOS.command** — открыть в Terminal |
| Linux | **INSTALL-LINUX.sh** — «Запустить в терминале» |

На macOS/Linux может потребоваться разрешить выполнение в свойствах файла.
Поведение двойного щелчка зависит от файлового менеджера. Если скрипт
открывается как текст, открой терминал в этой папке и выполни
`bash INSTALL-LINUX.sh` или `bash INSTALL-MACOS.command`.
Это терминальный мастер, не подписанный нативный установщик. Он не отключает
защиту операционной системы.

Мастер проверит файлы, Docker, архитектуру процессора и существующие установки.
Затем запросит:

1. Язык: `1` — English, `2` — Русский.
2. Порт кабинета: Enter оставит `8000`. Допустимы 1024–65535, кроме 8011.
3. Пароль владельца: 12–128 латинских букв, цифр или символов из подсказки.
   Ввод в терминале скрыт. Повтори пароль. Enter вместо пароля создаст случайный
   пароль — мастер покажет его один раз; сразу сохрани его.
4. Подтверждение: **`1` или Enter — установить; `0` — отменить**.
   Нераспознанный ответ приводит к повторному вопросу, а не отмене.

Отмена завершает мастер без создания установки и не считается ошибкой Docker.
Введённый вручную пароль не печатается обратно на экран.

Мастер создаст настройки, загрузит PostgreSQL, запустит сервисы и откроет браузер.
Первый запуск зависит от скорости сети и компьютера. После сообщения **Ready**
открой показанный URL, если браузер не открылся автоматически.

По умолчанию адрес — **http://localhost:8000**, логин — **admin@local**,
пароль — тот, который ты выбрал или сохранил из мастера.

## 4. Настроить рабочее пространство

Войди владельцем, добавь операторов и подключи нужные каналы через **Интеграции**.
Проверь полный маршрут: сообщение клиента → тикет → ответ оператора → получение
клиентом. ИИ включается отдельно; укажи провайдера и его ключ. Настрой резервные
копии до работы с реальными данными.

- [Подключение каналов](https://github.com/spooldesk/spool/blob/main/docs/INTEGRATIONS.md)
- [Руководство оператора](https://github.com/spooldesk/spool/blob/main/docs/USER_GUIDE.md)
- [Резервное копирование](https://github.com/spooldesk/spool/blob/main/docs/BACKUP_RESTORE.md)

## Повторный запуск, данные и обновление

Сначала запусти Docker, затем тот же установщик **из той же папки**.
Пароль, ключи, подключения и данные будут сохранены. Если папка, конфигурация
или версия не совпадают, мастер остановится без перезаписи данных.

Папка `spooldesk/` содержит конфигурацию. База, вложения и журналы находятся
в Docker volumes. Для резервной копии нужны и данные, и исходный ключ шифрования.
Не удаляй volumes и не используй Docker «Reset / Clean data» для исправления
ошибки установки.

Мастер предназначен для новой установки и повторного запуска своей установки.
Он не выполняет автоматическое обновление существующего сервера. Для обновления,
собственного домена и HTTPS следуй
[руководству развёртывания](https://github.com/spooldesk/spool/blob/main/docs/DEPLOYMENT.md).
После перехода на изменённую серверную конфигурацию управляй сервисами через Compose.
`localhost` доступен только на этом компьютере; для клиентов извне нужен доступный
сервер с HTTPS. Вендорский VPS для self-hosted не требуется.

## Что находится в архиве

| Файл или папка | Назначение |
| --- | --- |
| `README.txt` | С чего начать |
| `INSTALLATION.md`, `INSTALLATION_RU.md` | Инструкции на английском и русском |
| `TROUBLESHOOTING.md` | Ошибки и безопасное восстановление |
| `INSTALL-WINDOWS.cmd`, `INSTALL-MACOS.command`, `INSTALL-LINUX.sh` | Запуск для своей ОС |
| `installer/` | Служебные скрипты мастера |
| `package/` | Проверенные образы, исходники, сведения о версии и проверках |
| `SHA256SUMS` | Контрольные суммы файлов |
| `spooldesk/` | Появится после настройки; сохраняй эту папку |

При ошибке сначала смотри [TROUBLESHOOTING.md](TROUBLESHOOTING.md).
Версия rc — кандидат на выпуск; ручная проверка установки на целевых компьютерах
остаётся обязательной. Не отправляй пароли, `.env` или ключи в отчётах об ошибках.
